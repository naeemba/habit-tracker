# Settings: decisions

Settled questions. Read the entry before re-litigating it.

## settings-decision-1: The timezone is an environment variable for now

One user with one timezone does not need a row and a form yet, so `TIMEZONE`
in the environment stands in, behind one function to swap when the settings
page lands. One setting, one answer to "what day is it"
([research notes](../research.md) section 6). (2026-09-18, #4)

## settings-decision-2: The bonus is read when a day is written

So changing it never rewrites a day already paid; it becomes editable on the
settings page. (2026-09-18, #5)
